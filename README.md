# Mijn receptenboek

Mobiele recepten-PWA voor GitHub Pages.

## Publiceren

1. Ga naar **Settings > Pages** en kies **GitHub Actions** als bron.
2. Push naar `main`; de workflow publiceert automatisch `site/`.
3. Open de Pages-URL op iPhone in Safari en kies **Deel > Zet op beginscherm**.

## Recepten bijwerken

Wijzig `site/recipes.json` en commit/push de wijziging. De website wordt automatisch opnieuw gepubliceerd.
